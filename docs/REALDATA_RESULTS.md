# Real-data results (TUS 2024), GResearcher, 12 Oct 2026

Data: `TimeUse106PER.dta` (Survey_Year = 2024; 10,211,478 activity records; 450,457 diarists; 139,487 households; 9,969 FSUs) plus the household file `tus106HH` (139,489 rows) extracted from `TUS2024.Nesstar` with the open-source `nesstar-converter` 1.0.7 and the MoSPI DDI (catalog 236). All 12 household concepts matched. Code scheme: `nso`. Every diary sums to 1,440 minutes. Spouse link rate: 88.5%. Third-gender persons (Gender = 3) are excluded from the women-vs-men contrasts. Full run time on the Mac: about 15 minutes (panel 3 minutes, eight knits 12 minutes). Validation: `docs/realdata/validation.txt`.

**Benchmark caveat.** The NSO tables in `docs/nso_reference` describe the **2019** round, not 2024, so they cannot validate levels directly. A formal 2019-vs-2024 benchmark table is still to do (see handoff). Internal checks all pass: 1,440-minute identity, constant weights, no invalid codes, and FSU/household counts consistent with the NSO 2019 design scale.
