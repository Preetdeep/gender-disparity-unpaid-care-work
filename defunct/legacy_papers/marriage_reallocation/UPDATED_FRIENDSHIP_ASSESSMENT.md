## ISSUES FROM ORIGINAL REVIEW NOT YET ADDRESSED

### Major Issues Still Pending:

1. **Baseline Gender Gap Under-Discussed** 🔴
   - Table 2 shows never-married women participate LESS than never-married men (16.9% vs 19.2%)
   - This pre-marriage gender gap is important and under-discussed
   - Should add Section 4.1.1: "Pre-Marriage Gender Gap in Social Activities"
   - **Why this matters:** Marriage doesn't create the gender gap, it AMPLIFIES an existing one

2. **Age 25 Cutoff Justification** 🟡
   - Paper splits at age 25 for both men and women
   - But men's median marriage age is ~28 in India, not 25
   - Should either:
     - Use gender-specific cutoffs (25 for women, 28 for men), OR
     - Better justify using 25 for both
     - Consider finer age categories: 18-24, 25-34, 35-44, 45+

3. **Activity Code Frequency Table** 🔴
   - Need to show: How many observations in codes 81, 82, 83, 84, 85-89?
   - Are codes 85-89 actually present in the data?
   - If not, should say "codes 81-84" instead of "81-89"

4. **Selection Bias Direction** 🟡
   - Paper acknowledges selection bias (good!)
   - But doesn't discuss which direction it likely goes
   - If socially isolated women marry earlier → underestimates effect
   - If social women marry more easily → overestimates effect
   - Should add paragraph discussing most plausible direction in Indian context

5. **Mechanisms Section Too Speculative** 🟡
   - Section 7 lists 5 hypotheses but provides no empirical traction
   - Should either:
     - Cut to 1 paragraph, OR
     - Add suggestive evidence from the data (e.g., does penalty correlate with domestic work time?)

6. **Missing Robustness Checks** 🟡
   - Could add:
     - Weekday vs weekend analysis
     - State-level heterogeneity
     - Household income effects
     - Religious composition
