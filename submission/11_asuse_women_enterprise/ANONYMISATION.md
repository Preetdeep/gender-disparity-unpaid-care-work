# Anonymisation checklist (manuscript_anonymised.pdf)
- Author line replaced by "Manuscript anonymized for review" (params$blind = TRUE in knit.R).
- Statements and Declarations in the blind version omit name and affiliation; AI statement kept (journal requires it in Methods/declarations).
- No self-citation in the text; the cover letter mentions the separate PLFS manuscript without naming it.
- Before upload: check PDF metadata (pdfinfo package/manuscript_anonymised.pdf: Author field empty) and search the text for the author's name and email.
- Title page and cover letter go only to their own non-blind slots. Never upload manuscript_author.pdf to a blind slot.
